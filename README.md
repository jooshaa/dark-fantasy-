# dark-fantasy-

Cinematic realistic dark-fantasy horror experience in Roblox.

## Project Documentation

- [AGENTS.md](AGENTS.md) — mandatory workflow, team collaboration, and logging rules for all contributors and AI agents.
- [GRAPHICS.md](GRAPHICS.md) — live source of truth for environment direction, current state, implementation notes, audit log, and next priorities.
- [.agents/skills/roblox-blender-asset/SKILL.md](.agents/skills/roblox-blender-asset/SKILL.md) — Blender-to-Roblox asset creation, validation, and export specification.

## Collaboration Rule

Whoever works on this project, **their agent must always record what was changed, how it was implemented, what was verified, and any known limitations** in `GRAPHICS.md` (and in clear Git commits) before finishing a task.
